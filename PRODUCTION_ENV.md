# Cashh Radar — Production Environment Variables

Set secrets in the hosting dashboard, never in GitHub and never in chat.

## Core

| Variable | Needed | Purpose |
|---|---|---|
| `CASHH_SECRET_KEY` | Yes | Signs/security-related application state; Blueprint generates it. |
| `CASHH_ADMIN_EMAIL` | Yes | Initial owner login. |
| `CASHH_ADMIN_PASSWORD` | Yes | Initial owner password. |
| `CASHH_SUPPORT_EMAIL` | Yes | Public policy/support contact. |
| `CASHH_COOKIE_SECURE=1` | Yes | HTTPS-only production session cookie. |
| `CASHH_DEV_MODE=0` | Yes | Disables development-only behavior/docs/tokens. |
| `CASHH_PUBLIC_URL` | Optional on Render | Override automatic `RENDER_EXTERNAL_URL`, especially after custom domain. |

## Scheduler / operations

| Variable | Launch default |
|---|---|
| `CASHH_SCHEDULER_ENABLED` | `1` |
| `CASHH_SCHEDULED_SOURCES` | `grants_gov` |
| `CASHH_BACKUP_DIR` | `/app/data/backups` |
| `CASHH_METRICS_TOKEN` | generated by Blueprint |

## Email

`SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `SMTP_TLS`.

Set `CASHH_REQUIRE_EMAIL_VERIFICATION=1` only after SMTP delivery is tested.

## Stripe

`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_PRO`, `STRIPE_PRICE_TEAM`.

## Optional sources

`USAJOBS_API_KEY`, `USAJOBS_EMAIL`, `CASHH_LEVER_SITES`.

## Team/API limits

`CASHH_TEAM_SEAT_LIMIT`, `CASHH_API_PRO_RATE_LIMIT_PER_MINUTE`, `CASHH_API_ORG_RATE_LIMIT_PER_MINUTE`.
